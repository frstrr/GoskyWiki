# 多平台文章同步发布方案

## 核心结论

Wechatsync 是当前最成熟的开源多平台文章同步工具。通过 Chrome 扩展 + CLI + MCP 三种接入方式，可以将写好的文章一键同步到 29+ 平台，且数据不经过第三方服务器。

## 推荐工作流

### 标准发布流程

1. 在本地编辑器或 Obsidian 中完成文章撰写（Markdown 格式）
2. 在浏览器中登录目标平台账号（知乎、掘金、头条等）
3. 选择同步方式：
   - **Chrome 扩展**：打开文章页面，点击扩展图标，选择目标平台
   - **CLI**：`wechatsync sync article.md -p zhihu,juejin,csdn`
   - **MCP**：在 Claude Desktop / AI 工具中自然语言指令同步
4. 在各平台检查草稿，二次编辑后手动发布

### AI 辅助发布流程

1. 用 AI 工具（Claude、GPT 等）完成文章撰写
2. 通过 MCP 协议直接调用 Wechatsync 同步
3. 或在 Claude Code 中使用 Skill：`把这篇文章同步到掘金和知乎`

## 适用场景

- 自媒体运营：公众号文章同步到知乎、头条、百家号
- 技术博主：博客同步到掘金、CSDN、SegmentFault
- AI 写作用户：AIGC 内容一键发布
- 独立博主：WordPress/Typecho 同步到自媒体平台引流

## 关键配置

### 安装 CLI

```bash
npm install -g @wechatsync/cli
```

### 启用 MCP 连接

1. 在 Chrome 扩展设置中启用「MCP 连接」
2. 设置 Token
3. 配置 MCP Server 指向

### 平台 ID 速查

| 平台 | ID | 平台 | ID |

## 注意事项

- 同步前需在浏览器中登录各平台账号
- 默认同步为草稿模式，需手动确认发布
- 图片会自动转存到目标平台
- 支持网页智能提取正文并转为 Markdown

## 与 Obsidian 知识管理结合

可以将 Wechatsync 作为知识输出链路的末端工具：

1. 在 Obsidian 中积累和撰写知识笔记
2. 导出或整理为发布格式
3. 通过 CLI 或 MCP 同步到各平台
