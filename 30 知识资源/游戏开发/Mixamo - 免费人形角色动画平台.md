# Mixamo - 免费人形角色动画平台

## 核心结论

**Mixamo** 是 Adobe 旗下的**免费在线**角色动画工具链：上传人形静态模型 → 自动骨骼绑定 → 套用海量预设动画 → 导出 FBX。无需专业动画知识，就能为 Unity / 团结引擎 / 微信小游戏快速生成可用的人形角色动作。

官网：https://www.mixamo.com/（需 Adobe 账号登录，可免费注册）

## 何时用它

### 更适合

- 微信小游戏 / 独立游戏缺动画人力，需要快速补齐行走、待机、攻击、死亡等常用动作
- 已有 T-Pose 人形模型（FBX/OBJ），想跳过手工绑骨与手 K 帧
- 目标引擎是 Unity / 团结引擎，希望导出后直接进 Animator / 动画剪辑与混合树

### 不太适合

- 非人形生物、多肢、异形骨架（自动绑定按标准人形骨架匹配）
- 需要高度定制、品牌级演出镜头动画（预设库偏通用，精细度有限）
- 严格禁止使用 Adobe 账号 / 在线服务的团队流程

## 核心能力

| 能力 | 说明 |
|------|------|
| **自动骨骼绑定** | 上传 FBX/OBJ 静态人形模型，自动匹配标准人形骨骼 |
| **海量动画库** | 内置数百种预设（idle / walk / attack / death 等），覆盖游戏常用场景 |
| **在线预览与调整** | 可筛选动画、Apply 到当前角色；支持镜像（Mirror）、帧率调整（如 60→30fps） |
| **Unity 友好导出** | 下载可选 **FBX for Unity**（含骨骼与动画），也可选 T-Pose / A-Pose 初始姿势 |

## 推荐操作流程

1. **登录**：打开 Mixamo 官网，用 Adobe 账号登录并同意条款
2. **选模型**：`Characters` 用官方库；或 `UPLOAD CHARACTER` 上传自有 FBX/OBJ（建议 T-Pose、四肢对称、无多余部件；可先在 Blender 清理顶点与材质）
3. **套动画**：`Animations` 按关键词筛选 → 预览 → `APPLY`；按小游戏包体需要把帧率降到约 30fps
4. **导出**：`DOWNLOAD` → 选 **FBX for Unity**；需要后续融合动画时优先 T-Pose
5. **进引擎**：拖入 Unity / 团结引擎项目，用 Animator 状态机串联 Idle→Run→Attack→Death 等，用参数切换状态

## 实战优化要点

- **轻量化**：导出时启用 Keyframe Reduction，去掉冗余关键帧；小游戏场景优先 30fps
- **模型规范**：非标准人形、穿模部件、非 T-Pose 会导致绑骨失败或权重异常——上传前在 Blender 修好
- **状态机**：不要把所有动画堆在一个剪辑里；按状态拆分并做过渡，便于战斗与移动逻辑驱动
- **商用与条款**：免费使用仍受 Adobe / Mixamo 服务条款约束；上线前自行核对当前许可范围

## 与 unicore / 团结引擎的关系

- 导出的 FBX 可直接作为角色动画资源进入 Unity 系工作流（含团结引擎）
- 适合 unicore 类项目在原型期快速验证角色手感，再决定是否用定制动画替换
- 微信小游戏包体敏感：务必做关键帧削减与动画剪辑裁剪，避免整库动画无差别打进包内

## My takeaways

1. Mixamo 解决的是「人形绑骨 + 通用动作库」的产能问题，不是完整动画管线替代品。
2. 对微信小游戏最有价值的是：低成本拿到可跑通的一套基础动作，再按包体做帧率与关键帧优化。
3. 输入模型质量决定上限：T-Pose、干净拓扑、标准人形，比纠结选哪个动画更重要。
4. 与 AI 生成骨骼动画类新工具（如 SOON 等）可并存：Mixamo 偏「经典可靠、Unity 直出」；AI 方案偏「从零生成角色+动作」，选型按资产来源与引擎格式决定。
