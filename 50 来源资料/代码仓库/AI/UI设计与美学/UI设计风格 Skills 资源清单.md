# UI设计风格 Skills 资源清单（10 款）

## Source summary

来源文章：[10 种顶级 UI 设计风格 Skills，让你的 AI 生成界面从土味变惊艳！](https://www.toutiao.com/article/7645529296517284394/)（镜像：[AI星球](https://www.aixq.cc/33112.html)）。

核心问题：同样让 AI 写落地页，别人有设计感、呼吸感、品牌调性；自己的输出常是灰配色、挤间距、平庸字体——「AI 土味」。解法不是再调十遍 prompt，而是**换一套可调用的设计风格 Skill / DESIGN.md**。

本文把文章中的 10 个资源沉淀为可检索清单；高价值仓库另有专题页。

## 十款资源详表

### 1. Frontend Design Pro Demo

- **仓库**：https://github.com/claudekit/frontend-design-pro-demo
- **Demo**：https://claudekit.github.io/frontend-design-pro-demo/
- **要点**：11 种美学（瑞士极简、新拟态、玻璃拟态、粗野、黏土、极光、赛博、3D 超写实、撞色块、OLED 奢华、有机生物态）；每种含 master prompt、招牌效果、可生产代码；可作 Claude Code 插件 Skill。
- **专题**：[[50 来源资料/代码仓库/AI/UI设计与美学/frontend-design-pro-demo - 11种前端美学 Demo 与 Skill|frontend-design-pro-demo]]

### 2. UI UX Pro Max

- **仓库**：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **站点**：https://ui-ux-pro-max-skill.nextlevelbuilder.io / https://uupm.cc
- **要点**：设计智能 Skill；v2 Design System Generator；50+ 风格、大量色板/字体/品类推理规则；覆盖 React/Next/Vue/Flutter 等栈；含真实站点案例库。
- **专题**：[[50 来源资料/代码仓库/AI/UI设计与美学/ui-ux-pro-max-skill - UI设计智能 Skill|ui-ux-pro-max-skill]]

### 3. Awesome Claude Design

- **仓库**：https://github.com/rohitg00/awesome-claude-design
- **要点**：按美学家族整理 DESIGN.md / remix / Skills；README 贴代表品牌截图，适合「先看长什么样再选」。
- **专题**：[[50 来源资料/代码仓库/AI/UI设计与美学/awesome-claude-design - Claude 设计美学家族合集|awesome-claude-design]]

### 4. Awesome DESIGN.md

- **仓库**：https://github.com/VoltAgent/awesome-design-md
- **浏览**：https://getdesign.md/
- **要点**：Google Stitch 风格的 `DESIGN.md` 策展；每站含 DESIGN.md + preview.html / preview-dark.html；丢进项目根目录即可让 Agent 对齐该品牌语言。
- **专题**：[[50 来源资料/代码仓库/AI/UI设计与美学/awesome-design-md - 大厂 DESIGN.md 设计语言库|awesome-design-md]]

### 5. Anthropic Frontend Design（官方）

- **关联**：Anthropic / Claude Code 生态中的官方 frontend-design 类 Skill（文章指向 anthropics/claude-code）
- **风格**：Warm Editorial——赤陶橙 + 米白底 + Tiempos 衬线；anthropic.com 官网即该调性参考。
- **何时用**：要「官方 Anthropic 编辑气质」、偏内容/产品叙事站点时。

### 6. Bencium UX Designer Skill

- **仓库**：https://github.com/bencium/bencium-claude-code-design-skill
- **要点**：基于 Anthropic Skills 指南 + 作者设计哲学；两套——**Controlled**（生产级、WCAG/可访问性）vs **Innovative**（大胆突破）；作者官网即示例。

### 7. Taste Skill

- **仓库**：https://github.com/Leonxlnx/taste-skill
- **安装**：`npx skills add https://github.com/Leonxlnx/taste-skill`
- **要点**：「反 AI slop」前端框架；旋钮 VARIANCE / MOTION / DENSITY；另有极简、粗野、软高端、图生代码、生图参考板等多 Skill。
- **专题**：[[50 来源资料/代码仓库/AI/UI设计与美学/taste-skill - 反AI土味前端设计 Skill|taste-skill]]

### 8. SuperDesign

- **仓库**：https://github.com/superdesigndev/superdesign
- **要点**：开源 AI Product Design Agent；可在 VS Code / Cursor 中召唤，输出多风格 UI 草图供选择。

### 9. Neumorphism（新拟态）

- **仓库**：https://github.com/sridhar-sp/compose-neumorphism
- **要点**：Jetpack Compose 新拟态实现参考（浮雕/内凹柔和阴影）；适合移动端、播放器、轻量 Dashboard 风格参考，而非通用 Web Skill。

### 10. Neo-Brutalism（新粗野主义）

- **仓库**：https://github.com/dev-snake/brutalist-ui
- **要点**：Neo-brutalist React UI kit（Next.js + Tailwind + shadcn 风格组件）；高对比、粗边框、大字体；适合创意站/作品集/品牌官网。

## 使用建议

1. **先定方向再装 Skill**：用 awesome-claude-design / frontend-design-pro-demo 肉眼选型 → 再装对应 Skill 或拷 DESIGN.md。
2. **要「像某大厂」**：优先 awesome-design-md 拷贝对应 `DESIGN.md`。
3. **要「按产品品类自动配」**：ui-ux-pro-max。
4. **要「同一需求多气质变体」**：taste-skill 调三旋钮，或 frontend-design-pro 换美学编号。
5. **文章原文观点**：工具不稀缺，稀缺的是知道**什么场景调用哪种风格**。

## My takeaways

1. 这是一份 **AI 前端去土味工具箱索引**，不是单一框架；按场景挑 1–2 个即可，不必全装。
2. 生态已分成三条线：**推理出设计系统**（Pro Max）、**可调旋钮反 slop**（Taste）、**品牌/美学资产库**（DESIGN.md / Claude Design / Pro Demo）。
3. 新拟态与新粗野条目偏「风格参考实现」，体量与通用 Skill 不同，选型时勿与 Pro Max/Taste 混为一谈。
4. 与 wiki 中 Superpowers / mattpocock skills 互补：后者管工程纪律，本清单管**视觉语言**。
