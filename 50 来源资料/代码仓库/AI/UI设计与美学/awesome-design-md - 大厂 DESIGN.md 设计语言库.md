# VoltAgent/awesome-design-md - 大厂 DESIGN.md 设计语言库

## Source summary

**awesome-design-md** 收集从公开站点分析得到的 `DESIGN.md`：纯 Markdown 设计系统文档，专供 AI Agent / Google Stitch 阅读。理念：`AGENTS.md` 管怎么构建，`DESIGN.md` 管长什么样。

- GitHub：`VoltAgent/awesome-design-md`（约 **11.7 万+ Stars**）
- 浏览/请求：https://getdesign.md/
- 协议：MIT（声明不拥有品牌视觉所有权，仅公开 CSS 级 token 分析）

## 每个 DESIGN.md 含什么

| 板块 | 内容 |
|------|------|
| 视觉主题与氛围 | 情绪、密度、设计哲学 |
| 色板与角色 | 语义名 + hex + 用途 |
| 字体规则 | 家族与层级表 |
| 组件样式 | 按钮/卡片/输入/导航及状态 |
| 布局原则 | 间距、栅格、留白 |
| 深度与海拔 | 阴影与表面层级 |
| Do/Don't | 护栏与反模式 |
| 响应式 | 断点与触控 |
| Agent Prompt Guide | 可直接套用的提示 |

配套：`preview.html` / `preview-dark.html` 色板与组件可视化。

## 覆盖品类（示例）

AI 平台（Claude、Ollama、xAI…）、开发者工具（Cursor、Vercel、Linear…）、Fintech（Stripe、Coinbase…）、消费品牌（Apple、Nike、Spotify…）、汽车（Tesla、BMW、Ferrari…）以及复古 Web 专题等。完整列表以仓库/官网为准。

## 怎么用

1. 从 https://getdesign.md/ 或仓库选中目标品牌的 `DESIGN.md`
2. 复制到项目根目录
3. 告诉 Agent：「按本仓库 DESIGN.md 做页面」

## My takeaways

1. 找「**像某知名产品官网**」时，优先拷贝对应 DESIGN.md，比空喊「高端一点」有效。
2. 与 ui-ux-pro-max（推理生成）相对：本库是**品牌资产复用**。
3. 注意法律与品牌风险：仅作学习与内部原型更稳妥；对外商用需自行评估。
