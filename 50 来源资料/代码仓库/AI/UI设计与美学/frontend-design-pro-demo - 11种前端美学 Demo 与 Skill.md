# claudekit/frontend-design-pro-demo - 11种前端美学 Demo 与 Skill

## Source summary

**frontend-design-pro-demo** 把 11 种前端设计美学做成 live demo：每种含 master prompt、招牌视觉效果与偏生产向的纯 HTML/CSS 实现，并可安装为 Claude Code 插件 Skill。

- GitHub：`claudekit/frontend-design-pro-demo`
- Live Demo：https://claudekit.github.io/frontend-design-pro-demo/
- 协议：MIT
- 相关产品：https://claudekit.cc

## 11 种美学

| # | 风格 | 关键词 |
|---|------|--------|
| 01 | Minimalism & Swiss | 严谨栅格、大标题、杂志非对称 |
| 02 | Neumorphism | 浮雕、多重阴影、按下态 |
| 03 | Glassmorphism | 网格渐变、毛玻璃、backdrop-blur |
| 04 | Brutalism | 粗边框、硬阴影、破碎栅格 |
| 05 | Claymorphism | 黏土膨胀、糖果色 |
| 06 | Aurora / Mesh | 呼吸光斑、浮动玻璃 |
| 07 | Cyberpunk / Retro-Futurism | 霓虹、扫描线、HUD、故障 |
| 08 | 3D Hyperrealism | 写实材质、电影光、物理动效 |
| 09 | Vibrant Block | 撞色色块、粗边、脆 snap hover |
| 10 | Dark OLED Luxury | 纯黑+金、光标聚光、金箔渐变 |
| 11 | Organic / Biomorphic | 大地色、变形 blobs、波浪分隔 |

## 安装（Claude Code）

```text
/plugin marketplace add claudekit/frontend-design-pro-demo
/plugin install frontend-design-pro
```

示例提示：`use frontend-design-pro to create a frontend interface for <project> with <aesthetic> style.`

## My takeaways

1. 找「**可点开看效果 + 可复制 master prompt**」时优先本仓库。
2. 纯 HTML/CSS demo 利于教学与风格对齐，不一定等于你项目技术栈的组件库。
3. 与 Taste / Pro Max 可组合：Demo 选型 → Skill 落地。
