# rohitg00/awesome-claude-design - Claude 设计美学家族合集

## Source summary

**awesome-claude-design** 是面向 Claude / 编码 Agent 的设计美学策展库：按 aesthetic family 组织 DESIGN.md prompts、remix 配方、Skills，并附视频拆解与社区诚实评价。文章强调其 README 把各大美学代表品牌截图贴全，**适合选型前置「看图说话」**。

- GitHub：`rohitg00/awesome-claude-design`（约 **1100+ Stars**）
- 定位：美学家族地图 + 可 remix 资产，而非单一安装 Skill

## 核心价值

| 点 | 说明 |
|----|------|
| **美学家族对照** | 用真实品牌截图对比风格差异，降低「名字好听但不知道长什么样」的成本 |
| **DESIGN.md / prompts** | 可直接喂给 Claude 等代理 |
| **remix 配方** | 在家族内做变体，而不是从零措辞 |
| **社区信号** | 附带评价与拆解，减少盲从 |

## 适用场景

- 开工前 10 分钟定视觉方向
- 与 awesome-design-md 联用：这里定「家族」，那边拷具体品牌 `DESIGN.md`
- 给非设计背景的工程师做审美对齐材料
