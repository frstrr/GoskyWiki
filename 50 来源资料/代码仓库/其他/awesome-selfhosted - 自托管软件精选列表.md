# awesome-selfhosted - 自托管软件精选列表

## Source summary

**awesome-selfhosted** 是一份**自托管自由软件**精选列表：收录可在自有服务器上部署的网络服务与 Web 应用。项目本身几乎没有业务代码，却以「活地图」形式解决选型痛点——想自己搭服务，但不知道有哪些靠谱选择。

- GitHub：`awesome-selfhosted/awesome-selfhosted`（许可证以仓库声明为准，常用 **CC0-1.0** 表述；约 **31.7 万** Stars / **1.49 万** Forks）
- 官网（HTML，推荐浏览）：https://awesome-selfhosted.net/
- 定位：Free Software 自托管服务目录；非自由软件单独见 `non-free.md`
- 数据/自动化姊妹仓：https://github.com/awesome-selfhosted/awesome-selfhosted-data
- 创建于 2015-06，社区持续维护

## 核心能力

| 能力 | 说明 |
|------|------|
| **场景化分类** | 70+ 分类，按使用场景（通信、生产力、媒体、开发、网络、备份、AI 等）组织，而非按技术栈 |
| **统一条目格式** | `[名称](链接) - 描述。([源码](...)) \`许可证\` \`技术栈\``，便于扫读与 PR 贡献 |
| **质量门禁** | 要求自由软件、可自托管、活跃维护、有文档、有真实用户；Actions 查死链与停更项目 |
| **自由 / 非自由分离** | 主列表只收自由软件；限制性软件进 `non-free.md`，降低法律与理念混淆 |
| **多形态输出** | Markdown（GitHub）+ HTML 站 + data 仓，便于人读与程序消费 |
| **低门槛共建** | 贡献多为增改一行 Markdown，经自动化检查 + 人工审核合并 |

## 适用场景

- 个人/小团队想**摆脱 SaaS**，做自建邮箱、笔记、网盘、Git、监控等选型
- 需要按**场景**快速缩小候选，并看到许可证与技术栈标签
- 开发者做竞品调研、技术栈学习，或为自己的开源项目找曝光入口（提交 PR）
- 运维/隐私向用户建立「可自托管工具」知识地图

## My takeaways

1. **不是框架，是目录**：价值在「发现与对比」，不在可运行代码；做自托管选型时优先从这里或官网 HTML 版入手。
2. **准入与维护机制**（死链、停更检测 + 人工审 PR）是高 Star 的关键——列表可信度高于普通 awesome 堆砌。
3. 与 wiki 中已有的 [[50 来源资料/代码仓库/其他/Memos - 自托管轻量笔记工具|Memos]] 等单点工具笔记互补：本条目是**总索引**，具体软件再按需沉淀专题页。
4. 局限：英文为主、条目多导致检索偏弱；深度对比仍需结合官网文档与社区（如 r/selfhosted）。
