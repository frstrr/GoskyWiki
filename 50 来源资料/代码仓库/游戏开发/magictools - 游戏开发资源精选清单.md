# magictools - 游戏开发资源精选清单

## Source summary

**magictools**（仓库 [ellisonleao/magictools](https://github.com/ellisonleao/magictools)）是一份面向游戏开发的**精选资源清单（Awesome List）**：把常用素材、引擎与框架、音频、桌游、必看资料、广告与学习资源集中到一个 Markdown 列表里。作者 **Ellison Leão（ellisonleao）** 发起；仓库本身是链接目录，不是可运行引擎。

核心一句话：**按大类找「做游戏要用的东西」——素材、工具、引擎、音频、教程与社区；条目带授权标签，社区用 PR 补链接。**

- ~**16,966+** Stars / ~**1,202** Forks（2026-11-10 检索时约 1.7 万 Stars）
- 协议：**MIT**
- 语言：清单为主（Markdown）
- Topics：`awesome-list` / `gamedev` / `game-development` / `game-engine` / `art` 等
- 默认分支：`main`
- 创建于：2014-07-17

## 授权图例（License Legends）

清单用 emoji 标记每条资源的授权倾向，便于快速筛免费 / 开源选项：

| 标记 | 含义 |
|------|------|
| `:free:` | Free（免费） |
| `:tada:` | Open Source（开源） |
| `:moneybag:` | Paid（付费） |
| `:money_with_wings:` | Partially Free（部分免费） |

博客门户、视频/播客、Game Jam、社区等部分板块可不强制带授权标签。

| 特性 | 说明 |

## 分类速览（目录）

顶层大类（仓库 Table of Contents）：

1. **Graphics**：Assets/Placeholders、Spritesheet Tools、Bitmap Compression、Texture Tools、Character Generators、Tile/Level Editors、Animation、Vector/Image Editor、Modeling、Terrain Generators、Voxel Editors
2. **Code**：Engines and Frameworks、AI
3. **Audio**：Collections、Music and Audio Editors
4. **Board Games**：桌游相关工具与资源
5. **Must see**：Blogs and Portals、Books、Magazines、Videos/Podcasts、Game Jams、Project Management、Complete Game Sources、Communities
6. **Ads**：广告 / 变现相关
7. **Learn**：General Game Development、Computer Graphics

（中文介绍里常说「按八节分类」，实际顶层为上述 7 大类；Must see 下再拆出博客、书籍、Jam、社区等多个子节。）

## 提交规则（社区补链）

向清单提 PR 时需满足（以仓库 README 为准）：

- **只收游戏开发相关**链接，不收泛用工具
- **仅 HTTPS**
- GitHub 仓库链接一般需 **100+ Stars**
- 放入对应章节并保持**字母序**
- 条目需带授权标签（Blogs / Videos·Podcasts / Game Jams / Communities 等除外）

## 适用边界

### 更适合

- 开工前快速扫一眼：有哪些免费素材、关卡编辑器、引擎可选
- 按预算筛选（免费 / 开源 / 付费）
- 找 Game Jam、学习博客、完整游戏源码入口
- 为自己的知识库 / awesome 做二次索引

### 使用时要注意

- **定位是地图不是商店**：链接可能失效或跳转商品页；下载、授权与系统要求以各项目官网为准
- **「有条目」≠「可商用」**：需单独核对美术 / 音频 / 代码许可
- **清单会变旧**：社区维护活跃，但仍建议点开前再确认 Stars、维护状态与协议
- **与 open-source-games 分工不同**：本库偏**工具与资源**；[[50 来源资料/代码仓库/游戏开发/open-source-games - 开源游戏精选清单|open-source-games]] 偏**可玩开源游戏 / 重实现**本身

1. **开源地址已确认**：主仓 `ellisonleao/magictools`，游戏开发 Awesome List，约 17k Stars，MIT。
