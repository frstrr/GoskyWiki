# 2026-04-09 Obsidian 方法论对话沉淀

## Source summary

这次对话围绕“如何用 Obsidian 构建一个既方便个人查看，也方便 AI 检索和利用的个人知识库”展开，最终形成了方法论、vault 骨架和自动收录约定。

## Key excerpts

- 顶层采用稳定目录结构，用来管理知识流转和行动导向。
- 知识单元采用原子化 evergreen notes。
- 主题入口采用 MOC，既服务人类浏览，也服务 AI 检索。
- frontmatter / Properties 作为统一元数据层，为后续 RAG 和自动整理提供基础。
- 当前最终 vault 目标路径确认为 `D:\ObsidianWiki\selfWiki\个人笔记`。
- `obsidian-personal-kb` skill 用于后续按同一模式自动沉淀笔记。

## Decisions made

1. 默认 vault 使用 `D:\ObsidianWiki\selfWiki\个人笔记`。
2. 原有工作 wiki 内容迁移到个人笔记，旧库后续可删除。
3. 模板目录固定为 `_templates`。
4. 后续新增内容优先按 收件箱 / 来源资料 / 知识资源 / 知识导航 / 学习项目 路由。

## My takeaways

- 方法论本身已经不是抽象建议，而是进入了实际可执行状态。
- 后续关键不在于继续设计，而在于持续按统一 schema 收录内容。
- 最应该避免的是把所有内容重新丢回单篇大杂烩笔记中。
