# 元数据规范

## 通用字段

所有正式笔记尽量包含以下字段：

```yaml
---
id: 唯一标识
title: 笔记标题
type: inbox|source|evergreen|moc|project|area|system|archive
status: draft|active|evergreen|archived
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags:
  - 分类/主题
aliases:
  - 常见别名
summary: 一到三句摘要
---
```

## 笔记类型

- `inbox`：临时捕获，尚未整理。
- `source`：来源资料、摘录、课程或文章笔记。
- `evergreen`：长期维护的稳定知识笔记。
- `moc`：主题导航和索引页。
- `project`：阶段性学习项目。
- `area`：长期知识领域。
- `system`：知识库规则和说明。
- `archive`：归档内容。

## 稳定知识笔记

```yaml
moc:
  - [[40 知识导航/知识地图]]
source:
  - [[50 来源资料/来源笔记]]
related:
  - [[相关笔记]]
```

## 来源资料笔记

```yaml
source_type: book|article|video|course|doc|paper|conversation|other
source_url: 来源链接
source_author: 作者或机构
source_date: YYYY-MM-DD
```

## 学习项目笔记

```yaml
project_status: planned|active|paused|done
start_date: YYYY-MM-DD
end_date: YYYY-MM-DD
outputs:
  - [[产出笔记]]
```
