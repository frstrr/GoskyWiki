# 个人笔记

基于 [Obsidian](https://obsidian.md) 的个人长期学习库。顶层按知识流转组织：先捕获，再提炼成稳定笔记，再用导航页把主题串起来。

## 目录

```text
00 收件箱     临时想法、待整理问题、碎片记录
10 学习项目   课程、书籍、专题学习和阶段性目标
20 知识领域   长期维护的知识方向和能力域
30 知识资源   提炼后的稳定知识笔记（AI / 游戏开发 / 其他）
40 知识导航   主题入口和索引页
50 来源资料   原始资料（代码仓库、对话记录等）
90 归档       过期结构和不再作为入口的内容
99 系统       规则、规范和本库说明
_assets       图片和附件
_bases        Obsidian Bases
_templates    笔记模板
```

`30 知识资源` 和 `50 来源资料/代码仓库` 按大类分目录。同一主题跨多个大类时，正文只保留一份，其他目录放同名索引并链接到源文件。空分类目录不预建，有内容再新增。

## 笔记流转

1. 捕获：写入 `00 收件箱` 或 `50 来源资料`。
2. 提炼：拆成稳定结论，放入 `30 知识资源`。
3. 归属：长期方向挂到 `20 知识领域`。
4. 导航：更新 `40 知识导航` 的主题入口。
5. 归档：过期内容移入 `90 归档`。

正式笔记使用 YAML frontmatter。`summary` 用一到三句写清结论，方便人和检索工具读取。字段说明见 [元数据规范](99%20系统/元数据规范.md)。

## 用 Obsidian 打开

```bash
git clone git@github.com:frstrr/GoskyWiki.git
```

在 Obsidian 中选择 **打开本地仓库**，指向克隆下来的目录。入口笔记是 `Home.md`。

本库启用了核心插件中的模板、日记、关系图谱和 Bases，社区插件为 [Obsidian Git](https://github.com/Vinzent03/obsidian-git)。模板目录是 `_templates`。

## 版本管理

笔记、模板、Bases 和共享的 `.obsidian` 配置都在 Git 里。下列本机状态不提交：

- `.obsidian/workspace.json`、`workspace-mobile.json`、`cache/`
- `.trash/`
- `desktop.ini`、`Thumbs.db`、`.DS_Store`
